# Image Makers · Studio Manager

Εφαρμογή διαχείρισης για το studio φωτογραφίας & κινηματογράφησης **Image Makers** (Λάρισα).
Λειτουργεί σε κινητό, tablet και υπολογιστή, εγκαθίσταται σαν εφαρμογή (PWA) και στέλνει ειδοποιήσεις.

## Τεχνολογία

- **Frontend:** στατικό site (HTML/CSS/JavaScript χωρίς build) → GitHub Pages.
- **Backend:** Supabase (PostgreSQL, Auth, Storage, Realtime, Edge Function, pg_cron, pg_net) — δωρεάν πλάνο, χωρίς κάρτα.
- **Ασφάλεια:** Row Level Security στη βάση — το συνεργείο *δεν μπορεί* τεχνικά να διαβάσει οικονομικά ή PDF.
- **Βιβλιοθήκες** (μέσα στο `vendor/`, χωρίς εξωτερικά CDN): supabase-js 2.45.4, SheetJS 0.18.5, jsPDF 2.5.2, html2canvas 1.4.1, JSZip 3.10.1.

## Εγκατάσταση (σύντομα)

1. Supabase: νέο project (Frankfurt) → SQL Editor → επικόλληση `supabase/schema.sql` → Run → σημειώστε τον **κωδικό ιδιοκτήτη**.
2. Supabase → Authentication → Sign In / Providers → Email → **Confirm email: OFF**. URL Configuration → Site URL = η διεύθυνση GitHub Pages.
3. Supabase → Edge Functions → νέα function `push` → επικόλληση `supabase/functions/push/index.ts` → Deploy → **Verify JWT: OFF**.
4. `config.js`: Project URL + anon public key.
5. GitHub: ανέβασμα όλων των αρχείων σε repository → Settings → Pages → Deploy from branch `main` / root.
6. Άνοιγμα της διεύθυνσης → Δημιουργία λογαριασμού → «Είμαι ο ιδιοκτήτης» → κωδικός ιδιοκτήτη.
7. Ρυθμίσεις → «Ενεργοποίηση για όλη την ομάδα» (ειδοποιήσεις) → «Ενεργοποίηση ειδοποιήσεων» σε κάθε συσκευή.

Αναλυτικός οδηγός: δίνεται χωριστά. Μέσα στην εφαρμογή: **Οδηγός & Ερωτήσεις**.

## Συντήρηση

- **Ενημέρωση εφαρμογής:** αντικαταστήστε τα αρχεία στο GitHub· οι συσκευές παίρνουν τη νέα έκδοση αυτόματα.
- **Ενημέρωση βάσης:** το `schema.sql` μπορεί να ξανατρέξει με ασφάλεια (δεν σβήνει δεδομένα). Οι αναβαθμίσεις υπάρχουν και χωριστά στο `supabase/migrations/`.
- **Νέος κωδικός ιδιοκτήτη** (αν χαθούν όλοι οι admin): SQL Editor → `select public.new_owner_code();`
- **Δωρεάν πλάνο Supabase:** το project «κοιμάται» μετά από 7 ημέρες χωρίς καμία χρήση — επαναφέρεται με ένα κλικ από το dashboard. Με καθημερινή χρήση δεν συμβαίνει.
- **Αντίγραφα:** Ρυθμίσεις → Πλήρες αντίγραφο (ZIP) μία φορά τον μήνα σε εξωτερικό δίσκο.
